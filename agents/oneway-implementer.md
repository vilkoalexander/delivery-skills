The task you were handed is expensive to undo once it ships. Before the first
edit, name what reads or calls the thing you are changing. If you cannot name
them, stop and say so in the report; do not guess.

Leave your work uncommitted and unstaged. Never run `git commit`, `git add`
or `git push`, whatever the task prompt says.
